# Транспорт

[Главная](../README.md) · [Карта связей](../00_Navigation/Map.md)

Какие гарантии доставки получает приложение.

- [TCP — надёжный поток байтов](TCP.md) — Предоставляет приложениям упорядоченный поток байтов: подтверждает приём, повторяет потерянное и регулирует отправку..
- [UDP — независимые датаграммы](UDP.md) — Передаёт отдельные сообщения с небольшими накладными расходами.
- [QUIC — транспорт для HTTP/3](QUIC.md) — Совмещает защищённое установление соединения, несколько надёжных потоков и поддержку смены сетевого пути.
