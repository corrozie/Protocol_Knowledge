# IP — адресация и маршрутизация

[Главная](../README.md) · [Раздел](README.md) · [Словарь](../00_Navigation/Glossary.md)

## Зачем нужен

Доставляет пакеты между сетями. Адрес назначения помогает маршрутизаторам выбрать следующий узел, но IP сам по себе не гарантирует получение и порядок пакетов.

## Место в сети

Сетевой уровень; IPv4 в уроке. TCP и UDP передаются внутри IP; номера порта у самого IP нет.

## Как происходит обмен

1. Узел по своей маске определяет: получатель в локальной сети или за её пределами.
2. Для удалённого получателя выбирается шлюз; в IPv4 его MAC-адрес узнаётся через ARP.
3. Кадр доставляется шлюзу, а IP-пакет адресован конечному серверу.
4. Маршрутизаторы выбирают следующий переход и уменьшают TTL. В примере домашний роутер также выполняет NAT.
5. Ответ возвращается по маршрутам сети; NAT сопоставляет его с внутренним соединением.

## Пример

Ноутбук 192.168.1.10 отправляет запрос серверу 203.0.113.10 через шлюз 192.168.1.1. Это учебные адреса, а не инструкция по подключению к реальному серверу.

## Что важно различать

NAT — отдельный механизм, не обязательное свойство IP. MAC-адрес следующего узла и IP-адрес конечного получателя выполняют разные задачи.
