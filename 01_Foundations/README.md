# Адресация и сетевые службы

[Главная](../README.md) · [Карта связей](../00_Navigation/Map.md)

Как узел получает параметры, находит адрес сервера и выбирает путь.

- [IP — адресация и маршрутизация](IP.md) — Доставляет пакеты между сетями.
- [IPv6 — адреса и поиск соседей](IPv6.md) — Использует 128-битные адреса.
- [DNS — имена и адреса](DNS.md) — Распределённая система записей о доменных именах.
- [DHCP — автоматическая настройка сети](DHCP.md) — Выдаёт узлу сетевые параметры на ограниченное время — срок аренды.
- [ICMP — диагностика и ошибки](ICMP.md) — Передаёт управляющие сообщения IP: проверку достижимости и сведения о проблемах доставки..
- [NTP — синхронизация времени](NTP.md) — Помогает согласовать часы компьютера с источником времени, учитывая задержку передачи..
- [BGP — маршруты между автономными системами](BGP.md) — Позволяет автономным системам обмениваться сведениями о достижимости IP-префиксов и выбирать пути с учётом сетевой политики..
