# DNS — имена и адреса

[Главная](../README.md) · [Раздел](README.md) · [Словарь](../00_Navigation/Glossary.md)

## Зачем нужен

Распределённая система записей о доменных именах. Позволяет узнать адрес сервера, почтовые серверы домена и другие сведения.

## Место в сети

Прикладной уровень; UDP и TCP, порт 53. Для IPv4 используется запись A, для IPv6 — AAAA; MX указывает почтовый сервер.

## Как происходит обмен

1. Клиент обращается к рекурсивному резолверу.
2. При отсутствии ответа в кэше резолвер получает у корня направление к зоне верхнего уровня.
3. Сервер TLD указывает авторитетные серверы нужного домена.
4. Авторитетный сервер возвращает запись.
5. Резолвер кэширует результат на срок TTL и отвечает клиенту.

## Пример

Браузер узнаёт адрес www.example.com, после чего может соединиться с веб-сервером. Клиент обычно не опрашивает корень самостоятельно.

## Что важно различать

DNS не загружает страницу. Кэш может сократить показанную цепочку. Обычный DNS не обеспечивает шифрование запросов.
