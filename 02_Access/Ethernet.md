# Ethernet — кадры и коммутаторы

[Главная](../README.md) · [Раздел](README.md) · [Словарь](../00_Navigation/Glossary.md)

## Зачем нужен

Обеспечивает передачу кадров в локальной проводной сети. Коммутатор использует MAC-адреса для выбора выходного порта.

## Место в сети

Преимущественно канальный уровень; семейство IEEE 802.3. Номера TCP/UDP-порта к Ethernet не относятся.

## Как происходит обмен

1. В IPv4 отправитель узнаёт MAC получателя или шлюза через ARP.
2. Коммутатор запоминает MAC источника и входной порт.
3. Широковещательный запрос передаётся по другим портам VLAN; нужный узел отвечает.
4. После обучения известный unicast направляется на нужный порт.
5. Для удалённой сети кадр идёт шлюзу, который создаёт новый кадр для следующего канала.

## Пример

Ноутбук читает файл с NAS: IP выбирает логического получателя, Ethernet доставляет кадры внутри локальной сети.

## Что важно различать

Коммутатор и маршрутизатор решают разные задачи. При переходе между каналами MAC-заголовки меняются; IP-адрес назначения обычно сохраняется, если его не преобразуют.
