# Modbus — обмен с промышленным контроллером

[Главная](../README.md) · [Раздел](README.md) · [Словарь](../00_Navigation/Glossary.md)

## Зачем нужен

Даёт клиенту возможность читать и изменять coils и регистры контроллера. Урок рассматривает Modbus/TCP в промышленной сети.

## Место в сети

Прикладной уровень; Modbus/TCP обычно TCP/502. Holding register хранит 16 бит; coil — двоичное состояние.

## Как происходит обмен

1. Инженерный клиент устанавливает соединение с PLC.
2. Function 03 читает holding registers.
3. Function 06 меняет значение одного регистра, например уставку.
4. Function 05 записывает один coil, например команду пуска.
5. При ошибке сервер возвращает exception response с кодом причины.

## Пример

Клиент читает измеренные значения, меняет заданный уровень и отправляет команду насосу. Значение адресов задаётся документацией конкретного устройства.

## Что важно различать

Классический Modbus/TCP не имеет встроенных шифрования и аутентификации. Существуют отдельные защищённые расширения. Учебный пример нельзя переносить на реальные установки без разрешения и знания технологического процесса.
