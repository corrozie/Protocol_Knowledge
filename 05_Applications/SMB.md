# SMB — общие папки в сети

[Главная](../README.md) · [Раздел](README.md) · [Словарь](../00_Navigation/Glossary.md)

## Зачем нужен

Предоставляет удалённый доступ к файлам и общим ресурсам с операциями открытия, чтения, записи и закрытия.

## Место в сети

Прикладной уровень; современный прямой доступ обычно TCP/445. Урок демонстрирует согласование SMB и вход через NTLM.

## Как происходит обмен

1. Клиент соединяется с сервером и согласует диалект и возможности.
2. SESSION_SETUP выполняет аутентификацию; в сценарии используются challenge и response NTLM.
3. TREE_CONNECT подключает общий ресурс.
4. CREATE открывает файл, READ получает данные.
5. CLOSE закрывает дескриптор, затем сессия может завершиться.

## Пример

Папка на NAS выглядит для пользователя как общий сетевой ресурс, хотя операции проходят по сети.

## Что важно различать

Вход в систему, подпись сообщений и шифрование — отдельные свойства. SMB3 поддерживает шифрование, но его фактическое использование зависит от настроек; возможна аутентификация Kerberos вместо NTLM.
