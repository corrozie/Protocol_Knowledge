# IGMP — подписка на multicast

[Главная](../README.md) · [Раздел](README.md) · [Словарь](../00_Navigation/Glossary.md)

## Зачем нужен

Позволяет IPv4-узлу сообщить ближайшему маршрутизатору, какие multicast-группы ему нужны. Само видео передаётся другим протоколом.

## Место в сети

Сетевой управляющий протокол непосредственно в IPv4, без TCP/UDP-порта. В уроке показано поведение IGMPv2; в IPv6 применяется MLD.

## Как происходит обмен

1. Приставка посылает Membership Report для выбранной группы.
2. Маршрутизатор организует получение группы со стороны провайдера.
3. Коммутатор с IGMP snooping направляет поток только на порты заинтересованных клиентов.
4. Периодические Query проверяют, остались ли подписчики.
5. Leave и последующие проверки позволяют прекратить ненужную доставку.

## Пример

Две домашние приставки смотрят один телеканал: от провайдера приходит один поток, а внутри сети он копируется на нужные порты.

## Что важно различать

IGMP не передаёт видео и не заменяет межмаршрутизаторную multicast-маршрутизацию. Порты с snooping определяются членством в группе, а не TCP-сессией.
