# Прикладные системы

[Главная](../README.md) · [Карта связей](../00_Navigation/Map.md)

Как организованы почта, файлы, звонки, видео и промышленный обмен.

- [WebRTC — звонок между браузерами](WebRTC.md) — Набор технологий для передачи аудио, видео и данных в реальном времени.
- [SIP — установление телефонного вызова](SIP.md) — Управляет сеансами связи: регистрацией, приглашением, ответом и завершением разговора.
- [RTSP — управление потоком камеры](RTSP.md) — Позволяет запросить описание медиаресурса, настроить передачу, запустить и остановить воспроизведение..
- [RTMP — отправка прямой трансляции](RTMP.md) — Передаёт поток от программы вещателя к серверу приёма платформы.
- [IGMP — подписка на multicast](IGMP.md) — Позволяет IPv4-узлу сообщить ближайшему маршрутизатору, какие multicast-группы ему нужны.
- [SMTP — отправка электронной почты](SMTP.md) — Доставляет письмо от клиента на сервер отправки и далее между почтовыми серверами.
- [POP3 — загрузка почты](POP3.md) — Предоставляет простой доступ к сообщениям в почтовом ящике с акцентом на загрузку на клиент..
- [IMAP — синхронизация почтового ящика](IMAP.md) — Позволяет работать с письмами и папками на сервере, сохраняя состояние ящика между устройствами..
- [FTP — передача файлов двумя соединениями](FTP.md) — Разделяет команды управления и передачу данных.
- [SMB — общие папки в сети](SMB.md) — Предоставляет удалённый доступ к файлам и общим ресурсам с операциями открытия, чтения, записи и закрытия..
- [Modbus — обмен с промышленным контроллером](Modbus.md) — Даёт клиенту возможность читать и изменять coils и регистры контроллера.
