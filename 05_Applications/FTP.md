# FTP — передача файлов двумя соединениями

[Главная](../README.md) · [Раздел](README.md) · [Словарь](../00_Navigation/Glossary.md)

## Зачем нужен

Разделяет команды управления и передачу данных. В уроке показана загрузка файла в пассивном режиме.

## Место в сети

Прикладной уровень; управляющий канал TCP/21. В пассивном режиме порт данных сообщает сервер; TCP/20 связан с классическим активным режимом.

## Как происходит обмен

1. Клиент открывает управляющее соединение и входит через USER/PASS.
2. PASV или EPSV запрашивает параметры пассивной передачи.
3. Сервер сообщает адрес/порт или порт для канала данных.
4. Клиент открывает отдельное соединение и запрашивает файл командой RETR.
5. После передачи канал данных закрывается, а управляющий канал позволяет продолжить работу или отправить QUIT.

## Пример

Одна сессия управления может по очереди передавать несколько файлов через отдельные соединения данных.

## Что важно различать

Обычный FTP передаёт пароль и файлы без шифрования. FTPS — FTP с TLS; SFTP — другой протокол поверх SSH. Это разные решения.
