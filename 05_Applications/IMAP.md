# IMAP — синхронизация почтового ящика

[Главная](../README.md) · [Раздел](README.md) · [Словарь](../00_Navigation/Glossary.md)

## Зачем нужен

Позволяет работать с письмами и папками на сервере, сохраняя состояние ящика между устройствами.

## Место в сети

Прикладной уровень; TCP/143, с TLS с начала соединения — TCP/993. В уроке используется 993.

## Как происходит обмен

1. Клиент устанавливает защищённое соединение и проходит вход.
2. SELECT открывает INBOX и получает сведения о состоянии.
3. FETCH загружает метаданные или части письма.
4. Изменения флагов, например «прочитано», сохраняются на сервере.
5. При поддержке IDLE сервер сообщает о новых событиях без постоянного опроса.

## Пример

Письмо, прочитанное на телефоне, отображается прочитанным и на ноутбуке после синхронизации.

## Что важно различать

IMAP не отправляет письма адресатам: для этого используется SMTP. Серверное хранение не исключает локальный кэш сообщений.
