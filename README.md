# Как устроена сеть: база знаний по Protocol Explorer

Учебный проект по дисциплине **«Инфокоммуникационные системы и сети»** на основе [Protocol Explorer](https://protocol-explorer-alpha.vercel.app/).

## Веб-версия

[Открыть сайт базы знаний](https://corrozie.github.io/Protocol_Knowledge/)

У базы есть адаптивный сайт: поиск по всем материалам, оглавления, переходы между связанными темами, карта зависимостей и светлая/тёмная тема. Все статьи собираются из Markdown-файлов этого репозитория.

Локальный запуск: установить Node.js 22 или новее, выполнить `npm ci`, затем `npm run dev` и открыть адрес, который выведет сервер. Сборка для хостинга: `npm run build`; готовые файлы находятся в `dist/`.

Для Vercel: импортировать этот репозиторий, использовать настройки из `vercel.json` (сборка `npm run build`, каталог `dist`). Сервер и база данных для работы сайта не требуются. Прямые ссылки на статьи используют hash-маршруты и работают после обновления страницы.

Здесь собраны **все 39 тем сайта**: протоколы, технологии доступа и архитектурные роли. Материал систематизирован в текстовых Markdown-файлах с относительными ссылками. Каждая заметка объясняет задачу технологии, ход обмена, пример применения и связи с другими темами.

## Как читать и открывать

**На GitHub:** открыть этот README и переходить по ссылкам. Ничего устанавливать не требуется.

**В Obsidian:** скачать репозиторий через Code → Download ZIP либо клонировать, распаковать и выбрать «Открыть папку как хранилище». Открыть README.md. Обычные Markdown-ссылки работают как внутренние связи; их можно просматривать через обратные ссылки и граф. Дополнительная [карта Obsidian Canvas](Knowledge_Map.canvas) открывается в Obsidian и показывает основные отношения. На GitHub её текстовый эквивалент — [карта связей](00_Navigation/Map.md).

**В текстовом редакторе:** все материалы остаются читаемыми UTF-8-файлами. Доступ к сайту для чтения заметок не нужен.

## Принцип организации

Папки сгруппированы по учебным задачам: подключиться → получить адреса → доставить данные → воспользоваться сервисом → защитить обмен. Это авторская структура, а не точное повторение трёх фильтров сайта. Защита пересекается с другими разделами: например, HTTPS находится рядом с HTTP, а WPA3 — в разделе безопасности.

Ссылки в блоке «Связи с другими темами» подписаны: они показывают, какая технология использует другую, что она защищает или с чем её нужно сравнивать. Общие понятия вынесены в [словарь](00_Navigation/Glossary.md), номера портов — в [указатель](00_Navigation/Ports.md).
