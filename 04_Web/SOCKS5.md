# SOCKS5 — универсальный прокси

[Главная](../README.md) · [Раздел](README.md) · [Словарь](../00_Navigation/Glossary.md)

## Зачем нужен

Позволяет приложению попросить посредника установить соединение к выбранному адресу. Не требует понимать прикладной протокол внутри.

## Место в сети

Прикладной протокол; TCP/1080 — стандартный порт сервера. Поддерживает CONNECT; также определены BIND и UDP ASSOCIATE.

## Как происходит обмен

1. Приложение устанавливает соединение с SOCKS-сервером.
2. Клиент предлагает методы аутентификации; сервер выбирает один.
3. При необходимости выполняется вход.
4. Клиент указывает команду, адрес и порт назначения; доменное имя может разрешить прокси.
5. После успешного CONNECT прокси пересылает байты между соединениями.

## Пример

Локальный динамический туннель ssh -D предоставляет приложениям интерфейс SOCKS для выхода через удалённый узел.

## Что важно различать

SOCKS5 сам по себе не шифрует пользовательский трафик. В методе username/password пароль также не защищён без внешнего безопасного канала.
