# Веб и посредники

[Главная](../README.md) · [Карта связей](../00_Navigation/Map.md)

Как веб-приложения обмениваются данными и какую роль играют прокси.

- [HTTP — запросы и ответы веба](HTTP.md) — Описывает обмен ресурсами: клиент отправляет запрос, сервер возвращает статус, заголовки и, при необходимости, тело ответа..
- [HTTPS — защищённый веб](HTTPS.md) — Передаёт HTTP через защищённое соединение: обеспечивает конфиденциальность, целостность и проверку подлинности сервера..
- [WebSocket — двусторонний обмен](WebSocket.md) — Поддерживает длительный двусторонний канал: сервер может отправлять сообщения без отдельного HTTP-запроса для каждого события..
- [HTTP Proxy — посредник клиента](HTTPProxy.md) — Принимает запросы от настроенного на него клиента и обращается к серверам от его имени.
- [SOCKS5 — универсальный прокси](SOCKS5.md) — Позволяет приложению попросить посредника установить соединение к выбранному адресу.
- [Reverse Proxy — вход к серверному приложению](ReverseProxy.md) — Принимает входящие соединения от клиентов перед группой серверов приложения.
