# HTTP — запросы и ответы веба

[Главная](../README.md) · [Раздел](README.md) · [Словарь](../00_Navigation/Glossary.md)

## Зачем нужен

Описывает обмен ресурсами: клиент отправляет запрос, сервер возвращает статус, заголовки и, при необходимости, тело ответа.

## Место в сети

Прикладной уровень. В уроке HTTP/1.1 поверх TCP, обычно порт 80. Методы: GET, POST, PUT, DELETE, HEAD.

## Как происходит обмен

1. Браузер разбирает URL и готовит запрос.
2. DNS предоставляет адрес сервера, если он ещё неизвестен.
3. TCP устанавливает соединение.
4. Клиент отправляет GET / с заголовком Host; сервер возвращает статус и содержимое.
5. Браузер обрабатывает HTML и при необходимости запрашивает дополнительные ресурсы.

## Пример

GET / HTTP/1.1 запрашивает главную страницу; 200 OK означает успешный ответ. 404 означает, что ресурс не найден.

## Что важно различать

Незашифрованный HTTP допускает чтение и изменение трафика посредником. Текстовое представление показано для HTTP/1.1: HTTP/2 и HTTP/3 имеют двоичное кодирование.
