# Защита и доверие

[Главная](../README.md) · [Карта связей](../00_Navigation/Map.md)

Что именно шифруется, кто подтверждает личность и где заканчивается защита.

- [TLS — защищённый канал](TLS.md) — Согласует ключи, подтверждает подлинность стороны сертификатом и защищает содержимое от чтения и незаметного изменения..
- [SSH — защищённый удалённый доступ](SSH.md) — Создаёт защищённый сеанс для удалённых команд, передачи файлов и туннелирования..
- [DNS over HTTPS — приватный канал DNS](DoH.md) — Передаёт DNS-сообщения через HTTPS к выбранному резолверу.
- [DNSSEC — проверка подлинности DNS](DNSSEC.md) — Добавляет цифровые подписи DNS-данных и цепочку доверия.
- [WPA3 — защита беспроводной сети](WPA3.md) — В режиме Personal использует SAE для аутентификации по паролю и усиливает защиту управляющих кадров..
- [RADIUS — централизованный доступ к сети](RADIUS.md) — Позволяет точке доступа передать решение о допуске серверу аутентификации.
- [WireGuard — защищённый IP-туннель](WireGuard.md) — Создаёт VPN между узлами с заранее настроенными открытыми ключами.
- [IPsec — IKEv2 и ESP](IPsec.md) — Набор механизмов защиты IP.
