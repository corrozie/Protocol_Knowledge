# DNS over HTTPS — приватный канал DNS

[Главная](../README.md) · [Раздел](README.md) · [Словарь](../00_Navigation/Glossary.md)

## Зачем нужен

Передаёт DNS-сообщения через HTTPS к выбранному резолверу. Скрывает содержимое этого участка обмена от обычного наблюдателя сети.

## Место в сети

Прикладной DNS поверх HTTPS; обычно порт 443 на транспорте выбранной версии HTTP.

## Как происходит обмен

1. Клиент выбирает DoH-резолвер и получает возможность связаться с ним.
2. Устанавливается защищённое HTTPS-соединение.
3. DNS-запрос передаётся методом GET или POST в согласованном формате.
4. Резолвер выполняет разрешение и возвращает DNS-ответ через HTTPS.
5. Клиент использует полученный адрес для отдельного соединения с целевым сервисом.

## Пример

В публичной сети наблюдатель видит соединение с резолвером, но не обычный открытый DNS-запрос к UDP/53.

## Что важно различать

Сам резолвер всё равно видит запросы. DoH не гарантирует подлинность записей зоны без DNSSEC и не скрывает весь последующий трафик. Первичное определение адреса резолвера — отдельная задача.
