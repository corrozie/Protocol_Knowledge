# RADIUS — централизованный доступ к сети

[Главная](../README.md) · [Раздел](README.md) · [Словарь](../00_Navigation/Glossary.md)

## Зачем нужен

Позволяет точке доступа передать решение о допуске серверу аутентификации. В уроке показана сеть 802.1X с EAP-TLS.

## Место в сети

Прикладной AAA-протокол; обычно UDP/1812 для аутентификации, UDP/1813 для учёта. Между клиентом и точкой доступа используется EAPOL.

## Как происходит обмен

1. Устройство начинает обмен EAP с точкой доступа.
2. Точка доступа упаковывает EAP в RADIUS Access-Request.
3. Access-Challenge продолжает диалог; TLS внутри EAP проверяет сертификат сервера.
4. В EAP-TLS клиент подтверждает себя сертификатом и подписью.
5. Access-Accept разрешает доступ; четырёхстороннее Wi-Fi-рукопожатие устанавливает ключи канала.

## Пример

У каждого сотрудника собственная учётная запись или сертификат вместо общего пароля всей организации.

## Что важно различать

Сертификат сервера следует проверять, чтобы не довериться поддельной сети. Не все RADIUS-схемы используют клиентские сертификаты. Обычный RADIUS/UDP не шифрует весь пакет целиком.
